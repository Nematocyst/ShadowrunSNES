Rearrange any map in the game

Maps in Shadowrun are built from about 550 building blocks (walls, desks, doors, cars, stairs) laid over a painted floor. This editor moves, adds, flips and removes blocks, repaints floors, adds, moves and deletes exits, walls and characters, then writes an IPS patch. Each block carries its own walls, so where Jake can walk changes with it.

  1. Open your Shadowrun (USA) ROM with the button or drop it here. The vanilla 1 MB ROM and the 2 MB Runner Pack ROM both work. It stays in your browser.
  2. Pick a map and a mode: Blocks, Floor, Exits & walls, or Characters.
  3. Export: you get a .zip with the .ips patch for that ROM.
Show

Selected block

Click a block on the map. Click the same spot again to reach the one behind it.
X, Y and height below 0 are drawn, but the game gives the block no walls there.

Floor tiles

Pick a tile, then click or drag on the map to paint. Alt+click picks up the tile under the cursor. Each map uses one tile set; the tiles below are this map's set ().

Selected box

Click an exit (green), a floor trigger (purple), a map wall (cyan), a sight blocker (orange) or a walking point (white, numbered) on the map, or pick one from the list. Drag to move it; Shift+drag to raise it.

All boxes on this map

New boxes appear in the middle of the view. A map whose boxes or characters were added or deleted is moved to free space at the end of the ROM when you export (a small loader hook makes the game find it).

Selected character or object

Click a yellow dot or pick from the list. Drag to move; Shift+drag to raise.
Only the starting spot changes. Characters that walk a set route or are moved by scripts still do that.

Add a character or object

Anything placed on any map can be copied here; it appears in the middle of the view. Types marked ◆ keep a save slot (health, alive or gone). A copy of one gets its own save slot, so it lives and dies on its own (up to 19 per map, 256 in the whole game; past 24 the save file grows from 8 KB to 16 KB, and old saves still load; not for items or hireable runners). Types without ◆ (doors, fountains, signs, many props) can be copied freely.
