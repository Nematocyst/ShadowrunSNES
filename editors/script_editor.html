Change what happens in the game

Everything that happens in Shadowrun, from a door opening to a boss fight, is one of 936 small scripts. This editor turns each script into readable code, lets you change it, adds brand-new scripts, compiles it all back and writes an IPS patch. Decompiling and recompiling every original script gives the same game, frame for frame.

  1. Open your Shadowrun (USA) ROM. Vanilla and Runner Pack ROMs both work. It stays in your browser.
  2. Find a script by name, by who uses it (Hitman, Glutman's door…) or by its number from the Script Atlas.
  3. Edit the code. It recompiles as you type and points at the line if something is wrong.
  4. Need something the game doesn't have? "+ New script" makes one (numbered from $400) that any other script can run.
  5. Export: you get a .zip with the .ips patch for that ROM.
script $060 args 1 returns no
    self = arg1
    ADD_NUYEN(1234)        ; new line: +1,234 nuyen
    SET_VAR(0, 42)
    REMOVE_SELF(self)
    end

How the code reads

self the object running the script; L.w1 L.b5 its local word and byte slots (L.sb5 reads a byte as signed); var[42] the game's story variables; gb[$xxxx] gw[$xxxx] any byte or word in RAM bank $7E. Numbers: 200, -3, $02BD (hex). Maths and tests: + - * / % << >> & | ^ ~, == != < <= > >= (true is -1, false 0), bool(x), inc(x), dec(x), neg(x).

A script starts with its arguments waiting: take them first (self = arg1). end finishes it, end x also gives back a value. script_22F(self) runs another script. push, pop(), dup(...), drop and gosub appear where the original code juggles values in ways plain code can't show; leave them as they are.

Commands

Click a command to insert it. The number is how many values it takes; → means it gives one back. The last value is usually the object it acts on.
